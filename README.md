One line, under 200 characters, that gets you out of work and gets a laugh — a sick-day excuse a boss might half believe and a coworker would quote. Entry for the [make.fun bounty](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36).

The line: a yawn that goes wrong. No fever, no dog, no dead grandmother — just a jaw that locked itself shut and a mouth now only wide enough for soup.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes exactly one line to `/output/entry.txt` (124 characters, no trailing newline). It needs nothing but Node 22 and no network.
